# Grocify Frontend

This frontend follows the architecture described in the project report:

- `Vite`
- `React`
- `TailwindCSS`
- `TanStack Query`
- JWT-authenticated requests to the FastAPI backend

## Start

```bash
npm install
npm run dev
```

Set the API URL if needed:

```bash
VITE_API_URL=http://127.0.0.1:8000/api/v1
```
