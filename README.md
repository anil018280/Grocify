# Grocify

Grocify is an AI-driven grocery planning and food sustainability project focused on helping users manage pantry inventory, shopping lists, nutrition tracking, and meal planning in one place.

## Current Focus

- Building the frontend experience first
- Structuring the project for daily progress updates
- Designing a clean grocery dashboard workflow

## Frontend Start

The current frontend styling lives in `frontend/src/styles.css` and sets the visual foundation for the app with TailwindCSS plus a custom Grocify theme.
