# Grocify

Grocify is a prototype grocery management and meal-planning app focused on three MVP features:

- pantry tracking
- dashboard insights
- recipe recommendations based on current inventory

## Run the prototype

Open [index.html](/Users/boddamarathireddy/Desktop/Grocify/index.html) in a browser.

If you want to serve it locally from the terminal instead of double-clicking the file:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## What is included

- Pantry CRUD-style interaction: add and remove items
- Basic kitchen dashboard with waste-risk and value estimates
- Recipe suggestions ranked by pantry match
- Simple shopping and budget summary for the best recipe option
